# Player guide

1. Scan the room QR code or open the HTTPS link shared by the host.
2. Enter a nickname and join. Choose a nickname that is not already in use in that room.
3. Keep the same browser profile and site data for the event. The app stores an anonymous reconnect identity locally; it is not a password and clearing browser data removes it.
4. Wait in the lobby until Admin starts the round. Read the prompt and choose one meme before the server countdown ends. You may replace your submission until the deadline; repeated taps do not create duplicate submissions.
5. Wait for the reveal. In Community Mode, select one eligible meme and confirm. You cannot vote for your own entry, and a submitted vote is locked. Talent Mode does not ask players to vote.
6. View the result and leaderboard after the host publishes the winner.

If the network drops, keep the page open and restore Wi-Fi/mobile data. The app reconnects and restores the current game state. At the deadline, the server's clock decides whether an action was accepted. Do not open multiple tabs to submit or vote. Contact the host if your browser reports an expired round or cannot reconnect.
