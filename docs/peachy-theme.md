# Dreamy Peachy Cosmic × Pink Glass UI

Visual-only follow-up to Phase 02, dated 2026-11-05. Keep the existing routes,
gameplay, API/WebSocket contracts, persistence and media behavior.

## Direction and audit

The supplied references contribute translucent pink reflections, four-point stars,
holographic ovals and a midnight anchor. The new brief makes berry, blush, peach,
caramel and jasmine dominant; lavender supports depth and iridescence.

The current implementation still has indigo primary actions, lilac selected
states, blue haze and opaque white live Display/Admin panels. The live pages
supersede the original mock layouts, so verification must include real sessions.

## Sequential implementation

1. **Phase A — foundation:** central semantic palette, warm celestial atmosphere,
   blush/peach/dark glass surfaces, CSS/SVG stars and holographic ovals.
2. **Phase B — pages:** warm Player controls/selection/results, high-contrast dark
   Display with pink-peach blooms, dark Admin/Judge/CMS with warm reflected light.
   Bring Home, authentication, dialogs and the development showcase along.
3. **Phase C — verification:** required typecheck/test/build and relevant browser
   journeys, screenshot inspection, 320 px mobile/tablet/projector layouts,
   contrast, keyboard focus, touch sizes and reduced-motion/transparency checks.

Keep media untinted. Use darker berry for small text and white-label button
gradients; pastel swatches are not sufficient text colors on light surfaces.
Retain near-opaque reading surfaces over atmospheric layers. Decorations are
non-interactive and hidden from accessibility APIs. Record actual verification
and remaining limitations in `progress.md`.
